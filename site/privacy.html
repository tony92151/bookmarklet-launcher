Privacy Policy / 隱私權政策

Last updated: August 9, 2026 / 最後更新：2026 年 8 月 9 日

Summary / 摘要

Bookmarklet Script Manager works entirely on your device. Script names and source are stored only in chrome.storage.local.

Bookmarklet Script Manager 完全在您的裝置上運作。指令碼名稱與原始碼只會儲存在 chrome.storage.local。

The extension does not send scripts, page content, browsing data, or personal information to us or to third parties.

擴充功能不會將指令碼、網頁內容、瀏覽資料或個人資訊傳送給我們或第三方。

Data storage and transfer / 資料儲存與傳輸

Your saved script names and source code stay in your browser's local extension storage. They are not sent to a remote service, collected by us, or shared with third parties.

您儲存的指令碼名稱與原始碼會留在瀏覽器的本機擴充功能儲存空間。它們不會傳送到遠端服務、不會由我們蒐集，也不會與第三方分享。

Custom scripts are chosen by you and may read or modify the page where you run them. Review and trust a script before running it.

自訂指令碼由您自行選擇，並可能讀取或修改您執行它的網頁。請先檢視並確認您信任該指令碼，再加以執行。

Permissions / 權限

storage
Stores the script names and source you save locally in the browser.
在瀏覽器本機儲存您儲存的指令碼名稱與原始碼。
activeTab
Lets a script run only on the tab you actively choose when you invoke it.
只有在您主動選擇並執行指令碼時，才讓指令碼在該分頁上運作。
userScripts
Lets the extension run the custom scripts you have saved on the page you choose.
讓擴充功能在您選擇的網頁上執行您已儲存的自訂指令碼。

Support / 支援

For privacy questions or support, please open an issue in GitHub Issues.

如有隱私權問題或需要支援，請在 GitHub Issues 提出問題。
